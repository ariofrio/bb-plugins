Show the active project or section icon in the thread filter, use a folder
fallback without Project icons, and clarify the unfiltered state as Projects
or Projects and sections while retaining the All choice in the menu. Project
and section choices now expose the same settings, rename, local-path, and
removal actions as BB's built-in sidebar through hoverable action submenus and
right-click.
